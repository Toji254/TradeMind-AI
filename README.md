# TradeMind AI

TradeMind AI is a private project for building AI-powered trading intelligence tools.

## Initial Scope

- Market data ingestion
- Signal research and strategy experimentation
- Backtesting workflows
- AI-assisted analysis and decision support
- Risk management tooling

## Project Structure

- `src/` — application source code
- `tests/` — automated tests
- `docs/` — notes, specs, and architecture docs
- `data/` — local data files (ignored by git except placeholders)

## Getting Started

1. Create a virtual environment
2. Install dependencies
3. Add environment variables in `.env`
4. Start building modules in `src/`
